Datenschutzhinweise – Music Assistant Alexa

Diese Anwendung ist eine private Integration zur Steuerung der Musikwiedergabe auf Alexa-Geräten über Music Assistant.

Die Integration kommuniziert zur Authentifizierung und Steuerung mit Diensten von Amazon. Dabei können technische Geräteinformationen, Kontozuordnungen und Wiedergabebefehle verarbeitet werden.

Die Integration ist nicht für die öffentliche Nutzung vorgesehen. Eine kommerzielle Verwendung oder Weitergabe der Daten zu Werbezwecken ist nicht beabsichtigt.

Die Verarbeitung erfolgt im Rahmen der privaten Nutzung. Die beteiligten Dienste können eigene Datenverarbeitungen durchführen; hierfür gelten die Datenschutzhinweise der jeweiligen Anbieter.

Diese Seite wird über GitHub Pages bereitgestellt. Beim Aufruf können technische Zugriffsdaten durch GitHub verarbeitet werden.
